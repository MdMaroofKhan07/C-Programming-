# C Programming

A collection of C programming examples, practice problems, and notes created while learning the C programming language.

## 📌 About This Repository

This repository contains C programs covering fundamental concepts, problem-solving techniques, and practical examples. It is intended for beginners who want to build a strong foundation in C.

## 📚 Topics Covered

- Introduction to C
- Basic syntax and structure
- Variables and data types
- Input and output (`printf()` and `scanf()`)
- Operators and expressions
- Conditional statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Functions and recursion
- Arrays and strings
- Pointers
- Structures and unions
- File handling
- Practice problems and pattern programs

> Topics will be added as the repository grows.

## 🛠️ Requirements

To compile and run the programs, you need:

- A C compiler, such as GCC
- A code editor, such as Visual Studio Code (optional)



### 3. Compile a C program

For example, if your file is named `hello.c`:

```bash
gcc hello.c -o hello
```

### 4. Run the program

**Windows:**

```bash
hello.exe
```

**Linux / macOS:**

```bash
./hello
```

## 💻 Sample Program

```c
#include <stdio.h>

int main(void) {
    printf("Hello, World!\\n");
    return 0;
}
```

**Output:**

```text
Hello, World!
```
